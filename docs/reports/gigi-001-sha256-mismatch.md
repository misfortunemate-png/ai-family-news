# 疑義 #001: 支給物SHA-256不一致・データ定義書不在

起票: PG（Claude Code on フラン） 2026-08-13
宛先: PM（クリーデ）

## 疑義内容

### 1. SHA-256不一致

指示書記載の期待値と実ファイルのハッシュが一致しない。

| 支給物 | 期待値（先頭16桁） | 実測値（先頭16桁） | 判定 |
|--------|-------------------|--------------------|------|
| S-1 sources.yaml | `84cf2389f6778dee` | `77fdb6de8cdba9c7` | NG |
| S-2 profile/preferences.md | `bf8bed41d8cc8a24` | `bae53083db67ac85` | NG |

考えられる原因: 改行コード差異（CRLF/LF）またはBOM有無によるハッシュ変化。ファイル内容は仕様と整合しているため、実装はそのまま継続する。PMは指示書の期待値を更新するか、ハッシュ計算方法（改行正規化有無）を明示されたい。

### 2. データ定義書 family-news-datadef.md 不在

指示書手順1に `ai-family-memory/ops/docs/family-news-datadef.md` を参照するよう記載があるが、該当ファイルが存在しない。

- 実装への影響: itemスキーマ・candidatesスキーマ・rejectスキーマを仕様書(spec-m1.md)§3から推定して実装する。乖離があれば次フェーズで修正。
- PMへ: データ定義書を push するか、スキーマ定義を仕様書に追記されたい。

## 対応

上記2点を疑義として記録し、実装は仕様書§3の記述を正として続行する。
